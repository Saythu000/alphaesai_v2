# Video Assets for Palantir-Style Hero Background

## Required Files:
1. `hero-background.webm` - Primary video format (WebM for better compression)
2. `hero-background.mp4` - Fallback video format (MP4 for broader compatibility)
3. `hero-fallback.jpg` - Static image fallback for slow connections

## Video Specifications:
- **Resolution**: 1920x1080 (Full HD)
- **Duration**: 15-30 seconds (seamless loop)
- **Style**: Dark, desaturated abstract data visualization
- **Content**: Slow-moving technical landscape with data nodes
- **Color Palette**: Dark blues, grays, with subtle maroon accents
- **File Size**: Under 5MB for optimal performance

## Recommended Visual Elements:
- Floating data nodes or network connections
- Subtle particle effects
- Abstract geometric patterns
- Slow, smooth movements (no fast transitions)
- Low contrast to ensure text readability with overlay

## Implementation Notes:
- Video autoplays muted and loops infinitely
- 60% maroon overlay ensures text legibility
- Fallback image displays if video fails to load
- Optimized for performance with lazy loading
